# 🔥 Top 20 VS Code Shortcuts (Vanilla HTML / CSS / JS)

## 1–7: Navigation & Workspace

- Ctrl + P — Jump to any file instantly

- Ctrl + Shift + P — Command Palette

- Ctrl + B — Toggle sidebar

- Ctrl + \` — Toggle terminal

- Ctrl + Tab — Switch between open files

- Ctrl + W — Close current file

- Ctrl + Shift + E — Focus Explorer

## 8–14: Editing & Selection

- Ctrl + D — Select next match

- Ctrl + Shift + L — Select all matches

- Alt + ↑ / ↓ — Move line

- Shift + Alt + ↓ — Duplicate line

- Ctrl + / — Toggle comment

- Ctrl + Space — Trigger suggestions

- Alt + Z — Toggle word wrap

## 15–17: HTML / CSS / JS Power Moves

- Tab — Expand Emmet abbreviation

- Ctrl + Shift + / — Wrap with tag (Emmet)

- F2 — Rename variable/function safely

## 18–20: Search, Problems & Formatting

- Ctrl + Shift + F — Global search

- Ctrl + Shift + M — Problems panel (ESLint/JS errors)

- Alt + Shift + F — Format document (Prettier or built‑in)
